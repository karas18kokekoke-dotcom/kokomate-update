# kokomate-update

Kokomate checks this file once a day to tell BOOTH buyers that a new version is out.
It holds no source code and no user data.

- `latest`: the newest version (e.g. `0.2.0`). Raise it only after the new version is on BOOTH.
- `page`: the BOOTH page that opens when the user presses 「アップデート」 (https://….booth.pm only).
- `notes`: one short line per language (ja / en / zh-Hans / zh-Hant / ko); English is used when a language is missing.
